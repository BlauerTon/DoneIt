Download & Install DoneIt

DoneIt Planner can be installed as a standalone app on your desktop computer or mobile phone:

Windows & Mac (Chrome & Edge)
Click the Install icon in the address bar at the top right, then select Install.
iPhone & iPad (Safari)
Tap the Share button at the bottom of Safari, scroll down, and select Add to Home Screen.
Android (Chrome)
Tap the menu button in the top right, then select Install App or Add to Home Screen.
